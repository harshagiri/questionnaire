# Pain Map Asset Set (Nerve + Spine First)

These SVG assets are original in-repo illustrations for production UI prototyping.

Files:
- `nerve-spine-front.svg`: Front body chart with central neural pathway emphasis.
- `nerve-spine-back.svg`: Back body chart with spine and bilateral nerve-root pathways.

Intended usage:
- Use as base image layers in questionnaire pain-map screens.
- Add interactive overlays (regions, path toggles, severity heat/halo) in the UI layer.
- Keep a consistent viewBox and aspect ratio to preserve hotspot coordinates.
